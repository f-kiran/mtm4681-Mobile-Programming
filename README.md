# mtm4681-Mobile-Programming

Practice code and related learning materials for MTM4681 Mobile Programming.
The course uses Flutter and Dart to explore mobile application development.


## Repository contents

This repository is intended to collect:

- Flutter and Dart practice exercises and examples
- Supporting notes and other course materials

## Getting started

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) and
verify your setup with `flutter doctor`. Each Flutter project can then be run
from its own directory with `flutter run`.
